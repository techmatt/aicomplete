# Ops

Generated by `aic-sim docs` from `crates/aic-core/src/op.rs` and `content/`; don't edit. An op is one thing content can print (`{"op": "gain", ...}`). **Printed** counts it across all content: 0 means rules code with nothing using it yet.

**Unprinted ops.** `counter_all`, `pushback`, `remove_botnets`, `one_player` are kept as a palette for future cards (`PALETTE_OPS` in `crates/aic-sim/src/docs/run.rs`). Every other op printed 0 times stays until the card set freezes.
