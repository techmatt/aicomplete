# aicomplete

**AI Complete**, a cooperative board game about AIs, being turned into a digital version.
A pure, deterministic Rust core simulates the rules; a native simulator and a wasm build for a JS
front end sit on top, holding no rules. Build and test are below; other areas have a page each:

- [docs/simulator.md](docs/simulator.md): `aic-sim run`, `compare`, `show`, `replay`, every flag, game records, the farm.
- [docs/agents.md](docs/agents.md): the agent ladder, the specs, the heuristic, the dominance checks.
- [docs/experiments.md](docs/experiments.md): experiment specs, outputs, measures, overlays, the
  band and the gate, budgeting a run, the seed ledger (*Fresh seeds for a gate*).
- [docs/speed.md](docs/speed.md): what a run costs and where it goes.
- [docs/scripts.md](docs/scripts.md): every script under `scripts/`.
- [web/README.md](web/README.md): the viewer, the sweep and the card viewer.
- [tools/card-art/README.md](tools/card-art/README.md): the card renderer, frames, icons, scenes, originals.
- [experiments/history.md](experiments/history.md): an index of past items' write-ups.
- [docs/principles.md](docs/principles.md): design pillars, difficulty targets, lenses, measures.
- [docs/cards.md](docs/cards.md): every player card (`scripts/cards/cards_doc.py`); pricing method in
  [docs/card-pricing.md](docs/card-pricing.md), rates in `configs/agents/values.json`.
- [docs/rules/](docs/rules/README.md): the rules as implemented, at `RULES_REVISION`, a file per area, mapped
  by its `README.md`; its tables are generated.
- [docs/rulebook.md](docs/rulebook.md): the player-facing rulebook, hand-written from the engine but for §21's
  difficulty table (`aic-sim docs` writes it): a rules change that moves the rest updates it.
  [docs/rulebook-friction.md](docs/rulebook-friction.md) ranks what was hard to say.
- [docs/rules-history.md](docs/rules-history.md): what each recent revision changed, each rule locked or a
  candidate (older rows: git).
- Generated by `aic-sim docs`: [docs/ops.md](docs/ops.md), every op content can print and how often;
  [docs/harms.md](docs/harms.md), every harm by kind of source (the fast lane fails if a distribution check
  breaks); [docs/player-aid.md](docs/player-aid.md), the house terms.
- [docs/architecture.md](docs/architecture.md): modules, configs, tunables, invariants, how to add a module,
  variant or content, the op schema, generated docs.
- [docs/qa-findings.md](docs/qa-findings.md): open bug-hunt findings, won't-fix rulings, where hunts find faults;
  read it before a hunt.
- [CLAUDE.md](CLAUDE.md): the working contract for executors.

## Layout

| Path | What it is |
|---|---|
| `crates/aic-core` | The rules engine (invariants and API: [docs/architecture.md](docs/architecture.md)). |
| `crates/aic-core/src/modules/` | A file or directory per rules area; shared code (`common`, `effects/`); `plan`, read-only forecasts of rules steps shared by the rule and the agents; the registry in `mod.rs`. |
| `crates/aic-sim` | Native CLI ([docs/simulator.md](docs/simulator.md)): agent ladder (`agents/`), experiment harness (`experiment*.rs`, `gate.rs`, `report/`), `farm.rs` (a read's games for remote workers), `play.rs` (`run`, `compare`, `replay`, traces), `docs/` (generates and checks docs), `prof.rs` (`profile` feature). |
| `experiments/` | Specs ([docs/experiments.md](docs/experiments.md)), and `results/<name>/`: committed cycle reports (old-revision records there, r6 to r14, don't load). Top level: the standing specs (`band`, `gate`, `gate-exploit`, `gate-c3`, `smoke`, `use`, `same`, `same-noplanner`, `ladder-v0`, `overlay-card-cost`, `sanity-line`). `farm/`: farmed specs (`read`, `cell-d2`, the latest item's). `archive/`: specs not tied to the current revision or refused by the binary today. |
| `crates/aic-wasm` | wasm-bindgen bindings, JSON strings in and out. |
| `crates/aic-farm` | The farm's wasm bundle: `aic-sim`'s farm in a browser tab, configs and `experiments/farm/` specs built in (docs/simulator.md, *The farm*). |
| `content/` | Data embedded at compile time, built from code primitives: `map.json` (pieces, layouts for 1–4 countries, setup), `alignment.json` (Unity and Discord decks), `projects.json` (the adversary's project deck), `cards`, `threats`, `adversary`, `ais`. |
| `drafts/adversary/` | The source of `threats.json`, `projects.json` and `adversary.json` (threat tiers, projects, the Militarist): edit these, not `content/` (`content/load_adversary.py` in [docs/scripts.md](docs/scripts.md)). |
| `configs/` | Game configs: modules, variants, every parameter. `baseline.json` is the baseline at `RULES_REVISION`: the deck, 2 countries (3 seat the Researcher), difficulty 0, every number still a candidate (`regen.py` derives `experiments/configs/` from it, and `three_seat.json`, the viewer's 3-seat game). Other country counts, difficulties, off-variants and optional modules are `--set` lines ([docs/simulator.md](docs/simulator.md)). `configs/agents/`: agent numbers, no rule (`values.json`, the value table; `strategies.json`; docs/agents.md). |
| `scripts/`, `docs/` | The pages listed above. |
| `tools/card-art/` | Card frames, icons, scenes and print. |
| `art/` | Committed frame masters and guides; scenes are in `art-originals/`, a git-ignored junction. |
| `picks/` | Matt's picks: the pickers' round manifests. |
| `web/` | Browser viewer (Vite + TS on `aic-wasm`): `cd web && npm install && npm run dev` builds the wasm (~9 s warm) and serves http://localhost:5173/. The card viewer (`npm run cards`, conductor's button), records, browser checks: [web/README.md](web/README.md). |

## Card text for review

`python scripts/cards/deck_text.py unity` prints a deck as plain text (name, tags, location, cost, each line);
`science threats1` several, `all` every deck, `--list` their names. It reads the generated docs: run
`python scripts/regen.py` after a content edit.

## Toolchain

Rust stable (built with 1.100), target `wasm32-unknown-unknown` (`rustup target add wasm32-unknown-unknown`);
wasm-pack (`cargo install wasm-pack --locked`); Node (built with 24) for the smoke test.

## Build and test

```sh
cargo build --workspace
cargo check --tests                           # a missing import in ~1 min, before a full test build
cargo test --workspace                        # fast lane, the default: ~6 s once built, ~20 s after an aic-sim edit
cargo test-all                                # full run, slow lane included: ~1 min on 6 test threads once built
cargo test-slow                               # the slow lane alone: ~50 s
cargo build --release -p aic-sim              # ~30 s after an aic-sim edit, ~45 s after aic-core, ~1 min cold
./target/release/aic-sim docs                 # regenerate the generated docs (--check: report only)
wasm-pack build crates/aic-wasm --target web  # ~20 s cold, ~9 s warm -> crates/aic-wasm/pkg (git-ignored)
node scripts/farm/build.mjs out/bundle        # the farm's wasm bundle (~1 min cold)
node scripts/wasm-smoke.mjs                   # native = wasm; needs the wasm-pack line's pkg, not web/src/wasm/
node scripts/wasm-parity.mjs [games]          # native = wasm, variant matrix: ~22 s at 2 games a variant and agent; rebuilds a stale pkg
```

**Test lanes.** The slow lane is the tests marked `#[ignore = "slow lane: ..."]`: whole search-agent games, the
greedy experiment grid, more seeds of fast-lane replay checks. `test-all` and `test-slow` alias
(`.cargo/config.toml`) `cargo test --workspace -- --include-ignored` and `-- --ignored`; one slow test:
`cargo test-slow <name>` (a `-p aic-sim` build differs from the workspace's: ~1 min rebuild each way). Anything after
an alias goes to the test binary, no second `--` (`crates/aic-sim/tests/args_guard.rs`): `--test-threads=3` caps test
threads; `CARGO_BUILD_JOBS=3` caps build jobs (a `-j` stops in a second, like a fast pass: check the exit code).
Times are this machine's, idle; a cold test build is ~2.5 min. Test binaries run in turn, so a lane takes about
the sum of their slowest tests: split a loop over agents, variants or independent plays into tests or scoped threads. Search agents are slow in the test build (the seat-terms cache's `debug_assert` recomputes each hit;
`opt-level` 3 bought little): a whole-game test takes cheap agent params. No doctests (`doctest = false`). A red
crate stops the run: `cargo test --workspace --no-fail-fast [-- --include-ignored]`.

**Rules changes:** the fast-lane `golden_game` test pins the final state of one fixed game (baseline, seed
`u64::MAX`, action *k* = legal action `(k × 7919) mod count`). For an intended rules change, bump `RULES_REVISION`
in `crates/aic-core/src/lib.rs` (and `docs/rulebook.md`'s line 3 by hand: `aic-sim docs` refuses it stale), then
`GOLDEN_REVISION` and `GOLDEN_FINGERPRINT` in `crates/aic-core/src/tests/mod.rs` and `GOLDEN` in
`scripts/wasm-smoke.mjs` (`wasm_smoke_expects_the_golden_fingerprint` fails until it and `GOLDEN_CONTENT` match). The
fingerprint covers the config and the final state less its measures (`stats`): a rename that plays the same moves it
with no bump; a new counter doesn't. `GOLDEN_CONTENT_HASH` (wasm-smoke `GOLDEN_CONTENT`) pins the content hash over
raw bytes: a content-only edit moves it, with no bump unless play changes. Set it first, from `regen.py`'s "content
hash" line; then a `golden_game` run (revision and fingerprint are checked as a pair before the hash) gives the
fingerprint: the failing assertion's left side. Copy both, never type them.
A new phase goes in `configs/baseline.json`'s `round` list and in every lab test config that lists its neighbor
(`adversary.compute` beside `adversary.reveal`), or it silently never runs there.

**This machine.**

- Content and `configs/agents/` are compiled into `aic-sim` (`include_str!`): a `values.json` edit needs a rebuild.
  Game configs are read from the working directory, so an old binary runs from an old tree:
  `git archive <rev> configs | tar -x -C out/old`.
- A fresh worktree has no `web/node_modules`: `npm ci` in `web/` (~1 min) before `npm run cards:fit`.
- 6 cores, 12 threads: 12 workers give about 6 × one, not 12 ×. Timing has no warning of other load: two
  separate runs don't compare; `speed.py pair` does.
- `samply` waits on a UAC prompt: profile with `bench/profile_win.py` (docs/speed.md, *Profiling*).
- `wmic` and `tasklist` hang under load: use PowerShell `Get-Process`.
- A Bash background call's `timeout` is its kill limit (default 10 minutes); a waiter killed at it can leave
  `bash.exe.stackdump` in the repo root: delete it. Git Bash loops overrun their `timeout` when every thread is
  busy. `timeout N cargo test` under load kills the compile with no reason given: background it with a log.
- Windows can't replace a running exe: run a copy in `out/` (never `%TEMP%`) while building another.
- A failed cargo build leaves the old exe in `target/release`: a launcher that copies it and starts a run checks
  the build's exit code (`scripts/run_sim.ps1` does). Editing source during a build breaks it or bakes in a mix.
- Concurrent builds in one target dir corrupt incremental objects (LNK2019 on anon symbols):
  `cargo clean -p aic-core -p aic-sim -p aic-wasm`.
- Checkouts sharing a `CARGO_TARGET_DIR` share `release/aic-sim.exe` and its fingerprints, so old against new can
  compare a binary with itself: give each its own, and `md5sum` both binaries before a `pair` or `same_play`.
- Python writes cp1252 and CRLF to `open(p, 'w')` and a redirected stdout: scripts
  `sys.stdout.reconfigure(encoding='utf-8', newline='\n')` and open with `encoding='utf-8', newline='\n'`. A Bash
  `read -r` loop over a CRLF list hands on `20\r`.
- A conductor `wait_for` on a cargo test log needs `fail: "FAILED"`: passing test names hold "errors" and
  "panicked" (`a_panicked_seed_...`), which the default pattern stops on.
- Git Bash `rm -rf out/x` also deletes `out/x.exe` (Cygwin's `.exe` matching). Bash turns `/c/...` into `C:/...`
  for a native program but not after an `=`: a `FILE=SPEC` argument takes `C:/...` paths.
- PowerShell `*>` writes UTF-16 logs, which Git Bash `grep` reads as empty: read them in PowerShell or write with
  `-Encoding utf8`.
- A marker from `Start-Process powershell -Command '...'` may never appear: end a log from a `-File` script.
